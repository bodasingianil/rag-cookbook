# 📚 RAG Cookbook

A hands-on collection of **Retrieval-Augmented Generation (RAG)** implementations, experiments, and learning notebooks.

This repository focuses on understanding RAG concepts from the fundamentals to more practical and production-oriented approaches.

## 📂 Hands-on Notebooks

| Notebook | Description |
|---|---|
| `RAG_From_Scratch.ipynb` | Build a RAG pipeline from scratch to understand the core concepts and workflow. |
| `RAG_From_Scratch_Production_Ready.ipynb` | Explore a more production-oriented RAG implementation and best practices. |
| `RAG_Using_LlamaIndex.ipynb` | Implement RAG using the LlamaIndex framework. |
| `Tokenizer_(1).ipynb` | Hands-on exploration of tokenization and how text is processed for LLMs. |

## 🧠 Concepts Covered

- Retrieval-Augmented Generation (RAG)
- Document ingestion and processing
- Text chunking
- Tokenization
- Embeddings
- Vector databases
- Similarity search
- Context retrieval

- LlamaIndex
- Building RAG pipelines from scratch
- Production-oriented RAG concepts
